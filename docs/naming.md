# Name screen

Snapshot: 2026-07-29. This is a practical collision screen, not a legal trademark
opinion.

## Decision

The released name is **Marktake**, a compact description of the core action:
mark the take.

The working name FrameReview was rejected because it sits too close to Frame.io,
FrameCheck, and a crowded field of generic "Frame" review names. It is also weak
as a searchable identity.

## Checks performed

- General web and software-name searches for `Marktake`, `"Marktake" software`,
  and `"Marktake" app` found no current, relevant media-review product.
- GitHub repository and user search found no relevant exact-name project.
- npm returned no `marktake` package and no `@marktake/core` package.
- PyPI and crates.io returned no `marktake` project.
- The intended repository `arturict/marktake` did not exist before publication.
- Namecheap's live availability check reported `.com`, `.org`, `.dev`, `.app`,
  `.video`, and `.io` as available at the time of checking. No domain was bought.
- Search found an unrelated dissolved historical company and unrelated usernames,
  not a current software brand.

Rejected candidates included CueSlate, Pinreel, Reelpin, ReviewDock, FlickMark,
RoughNote, Scrubnote, ProofPin, ReelCue, ClipCue, Scenote, and TakeMark because
current products, organizations, repositories, or adjacent creative uses made
confusion more likely.

## Limits

Search engines and registries do not establish trademark clearance. Availability
can change at any time, and a domain result is not ownership. Contributors should
not purchase a domain or register a mark on behalf of the project.
