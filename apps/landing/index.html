01 / The useful middle

Not another Frame.io clone.

Marktake stops where a small review workflow stops. It does not become your editor, asset library, project suite, or hosting company.

Keep

Precise feedback

Rational frame mapping, time-linked notes, on-image marks, and threads.

Keep

Simple decisions

Versions, resolved notes, approval, and change requests in one room.

Cut

Platform gravity

No MAM, AI, live co-watch, NLE plug-ins, S3, queues, or broad formats.

03 / One review loop
  1. 01

    Export a review copy

    H.264 MP4 or VP8/VP9 WebM at a constant frame rate.

  2. 02

    Send a private link

    The guest secret stays in the URL fragment and becomes a secure session.

  3. 03

    Resolve the cut

    Reply, resolve, upload the next version, and record the decision.

04 / Local by architecture

One process. One volume. No hidden media path.

FFprobe validates the real streams. FFmpeg strips container metadata by remuxing without re-encoding. SQLite keeps the review state beside random-name media files.

05 / Start with one cut

Run it where your review media belongs.

Marktake is free software. Your costs are the machine, storage, bandwidth, domain, TLS, backups, and operations you choose. This static Vercel site does not host your videos.

Docker Compose 
git clone https://github.com/arturict/marktake.git
cd marktake
export MARKTAKE_ADMIN_PASSWORD="choose-a-long-random-password"
docker compose up -d

Use HTTPS and secure cookies before exposing an instance to the internet.
