# Roadmap

Marktake stays useful by remaining smaller than a general creative operations
platform. Items here are direction, not delivery promises.

## Now: v0.1

- One owner password and scoped guest review links.
- Browser-ready CFR MP4 and WebM review copies.
- Frame notes, markups, threads, versions, statuses, and decisions.
- One container, local SQLite, and one local media volume.

## Next, only after real use

- Export comments as plain CSV and editor-friendly marker formats.
- Optional guest link read-only mode that separates comments from decisions.
- Backup integrity command and orphaned-file diagnostics.
- Documented reverse-proxy examples for Caddy and nginx.
- Better keyboard-only annotation and timeline navigation.

## Later, if evidence supports the cost

- Still-image review.
- Object storage as an optional adapter.
- Notification webhooks with explicit privacy controls.
- Multiple owner accounts and audit history.

## Explicit non-goals

- A Frame.io clone, NLE, media asset manager, cloud storage vendor, or task
  management suite.
- Automatic transcoding in the request process.
- Live co-watching, AI summaries, watermarking, DRM, mobile apps, or NLE plug-ins
  in v0.1.
- Arbitrary creative file formats.
